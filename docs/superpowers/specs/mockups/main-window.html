Merged direction: dark & light

Color identity from A, readability and native feel from B. The app follows your system appearance, so here are both.

  • From A: titles keep the project color, but softened (blended toward white in dark mode, toward black in light mode) so long lists stay easy to read.
  • From B: a thin color rail per project instead of divider lines, which groups the tasks without boxing them in.
  • Middle ground: rounded-square checkboxes (between A's squares and B's circles), with the emoji + colored header on each group.
  • Light mode: uses deeper versions of each color, since bright yellow on white would be unreadable.
